# AI Swing Trading Intelligence Platform – Figma Make Prompt

Create a modern AI-powered stock swing trading web application UI/UX for Indian stock market traders using FYERS APIs.
The application should feel premium, data-driven, intelligent, fast, and trader-friendly similar to Zerodha + TradingView + modern AI dashboards.

Design a complete responsive web application with dark/light mode support.

---

# Product Vision

This platform helps swing traders identify high-probability momentum stocks for short-term growth opportunities using:

* AI-powered stock scoring
* Technical analysis
* Volume breakout detection
* Sector strength analysis
* Dip-buy opportunity detection
* Portfolio monitoring
* Risk analysis
* Smart alerts

Target users:

* Retail swing traders
* MTF traders
* Momentum traders
* Short-term investors
